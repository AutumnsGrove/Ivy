# Security policy

Ivy handles email, so please report security problems privately.

**Report a vulnerability:** use GitHub's private vulnerability reporting on this repository
(Security tab, "Report a vulnerability"). Please don't open a public issue or pull request for it.

Include what you found, how to reproduce it, and the version or commit. You'll get an
acknowledgement, and a fix or an explanation, as soon as practical. This is a single-maintainer
project, so there are no guaranteed response times and no bounty.

**In scope:** the Ivy server and web app, for example HTML or attachment handling that escapes the
sandbox, request forgery, injection, or anything that exposes mail or credentials.

**Supported versions:** only the latest commit on `main`.
